scrapers-lib

A Python library that gathers product intelligence from across the consumer-tech web. Built in 2 weeks!

By Swarnim Bagre May 2026·v1.3.1
Problem

Product intelligence lives scattered across the consumer-tech web — manufacturer pages, retailers, news, video, forums — each with a different shape and scraping quirks of its own.

What it does

Scrapers-lib gathers from all five and emits two record types: point-in-time product snapshots, and verbatim mentions of named products.

Why this way

A library, not a service. Free-tier throughout, with fetchers grouped into tiers by how each source exposes data.

Challenges Faced solved or worked around · with what would unlock a proper fix
By design

Built without paid infrastructure (a scaling ceiling)

+
How I handled it

Free-tier infrastructure throughout: no paid proxies, no managed scraping, no premium APIs. Careful pacing keeps within free quotas.

What would unlock a proper fix

A budget unlocks proxy pools, commercial scraping, and premium data APIs for higher volume.

Solved

Retailer pages actively block scrapers

+
How I handled it

A slow, browser-mimicking approach reliably collects reviews from Amazon and Best Buy.

What would unlock a proper fix

Official merchant APIs (e.g. Amazon Selling Partner API) replace scraping with sanctioned, stable feeds.

Solved

Manufacturer sites use different, shifting back-ends

+
How I handled it

Six tailored fetchers (one per brand) plus a shared session helper for common patterns. Every site rebuild requires re-research.

What would unlock a proper fix

Direct partner data feeds from each manufacturer would replace per-site scraping with stable, structured access.

Working around

Reddit closed self-service API access in late 2025

+
How I handled it

Switched to public JSON and RSS endpoints, the same data anyone can read without logging in. Caps at 100 posts per request; the library paginates from there.

What would unlock a proper fix

An approved Reddit API key would unlock authenticated quotas, private communities, and richer metadata.

Blocked

Best Buy product & price data sits behind closed developer keys

+
How I handled it

Built the official-API connector anyway, so it’s ready to activate; for now Best Buy product data stays dormant.

What would unlock a proper fix

A Best Buy Developer API credential turns it on immediately.
